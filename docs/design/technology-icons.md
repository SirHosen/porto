# Technology icon provenance

Retrieved 2026-09-16. Assets are local: no icon package, runtime CDN, tracking, or network dependency.

- `lib/tech-logos.json`: unmodified SVG path geometry from [Simple Icons](https://github.com/simple-icons/simple-icons/tree/4ba19240849175ab4b855a732ab98c0f87cfb714/icons), pinned commit `4ba19240849175ab4b855a732ab98c0f87cfb714`. Container colors follow the portfolio palette; no logo paths are distorted.
- Simple Icons collection: [CC0](https://github.com/simple-icons/simple-icons/blob/4ba19240849175ab4b855a732ab98c0f87cfb714/LICENSE.md); [disclaimer](https://github.com/simple-icons/simple-icons/blob/4ba19240849175ab4b855a732ab98c0f87cfb714/DISCLAIMER.md). Individual marks remain subject to their owners' trademark/brand rules; identification of the technology is not affiliation or endorsement.
- PHP mark: Colin Viebrock / PHP, [original logo source](https://php.net/download-logos.php), [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Geometry unchanged; monochrome presentation.
- `public/tech/riverpod.svg`: unmodified [Riverpod site SVG](https://github.com/rrousselGit/riverpod/blob/0313d051713158b11aeb6b698c57981563021dae/website/static/img/logo.svg), commit `0313d051713158b11aeb6b698c57981563021dae`. Copyright (c) 2020 Remi Rousselet; the upstream MIT notice is included at `public/tech/LICENSE-riverpod.txt`. The mark identifies Riverpod.
- React Three Fiber uses the React mark to identify its React renderer, not an invented dedicated R3F logo. PyQt uses the Qt mark for its Qt binding.
- Async, Scraping, Testing, Bayesian, Blade templates, Auth, DSP, PyInstaller packaging, Concurrency, HTTP / Proxy, and Logging use original functional line glyphs. They are not represented as official product logos. PyInstaller's packaging glyph is explicitly identified in its accessible disclosure.
- Original legacy `assets/js/logos.js` remains untouched. The current locally vendored paths retain the same established icon language while adding missing stack brands. Sources below allow verification of the exact current geometry.
